# dvbs2enc – DVB-S2 encoder for the TX tab

A DVB-S2 encoder for transport streams (EN 302 307-1) in plain C11, for the app's TX tab (the XIAO ESP32-C3 in its PC
streaming mode needs the host to send it ready symbols) and for tests on a PC. GPL-3.0-or-later.

- BBFRAME (TS, CCM, single stream), BB scrambling, BCH, LDPC, 8PSK bit interleaver, QPSK / 8PSK mapping, PLHEADER
  (pi/2-BPSK), pilots, PL scrambling (gold code 0).
- QPSK 1/4 … 9/10, 8PSK 3/5 … 9/10; normal (64800) and short (16200) FECFRAMEs; pilots on or off.
- Two framings: **whole packets per frame** (`s2enc_frame`, SYNCD 0, the stand-alone beacon's layout – a loop joins up)
  and a **continuous stream** (`s2enc_push` / `s2enc_stream_frame`, full data fields, packets across frames).
- Output: one phase index per symbol (symbol = e^(jπk/4)); `s2enc_pack_qpsk` packs QPSK as the ESP32-DATV firmware's
  `beacon.bin` (4 symbols per byte). About 1000 normal frames per second on a laptop.

Sources: written from the standard. LDPC tables: `ldpc_tables.h`, generated by `gen_ldpc_tables.py` from Ahmet Inan's
`dvb_s2_tables.hh` (0BSD). BCH polynomials: EN 302 307-1 Tables 6a/6b. No code from ESP32-DATV(-SA), whose licence
(PolyForm Noncommercial) does not allow it in a GPL app – its `make_beacon.py` and `dvbs2.py` serve only as test oracles.

## Tests

```sh
third_party/ESP32-DATV-RX/.venv/bin/python rx/test_dvbs2enc.py      # builds build/s2enc/s2enc with gcc
```
- A: bit-exact against `make_beacon.py` (beacon framing, QPSK, 26 cases);
- C: bit-exact against `dvbs2.Encoder` (continuous framing, QPSK and 8PSK, every rate, both frame sizes, 64 cases);
- B: decoded by leandvb + ldpc_tool (the receivers' decoder) back to the input TS.

leandvb does not decode normal-frame QPSK 3/5 and 5/6, nor short-frame 8PSK with ldpc_tool, even without noise, although
both encoders agree bit for bit: a limitation of the receiver (2026-10-15), listed in the test as known.

`s2enc` (the test CLI): `build/s2enc/s2enc [--const qpsk|8psk] [--rate 3/4] [--frame normal|short] [--pilots]
[--stream | --loop] [--packets N] [--frames N] [--format phase|qpsk] IN.ts OUT`.
